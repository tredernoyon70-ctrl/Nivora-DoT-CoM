আপনার পছন্দের পণ্য, এক জায়গায়

ফ্যাশন, গ্যাজেট এবং দৈনন্দিন প্রয়োজনীয় পণ্য দেখুন। পণ্যের দাম ও বিবরণ যাচাই করে অর্ডারের জন্য যোগাযোগ করুন।

আমাদের পণ্য

ডেমো পণ্য দেখানো হচ্ছে। Supabase সংযোগ করতে নিচের নির্দেশনা অনুসরণ করুন।
Supabase সংযোগের নির্দেশনা (সেটআপের জন্য)

এই ফাইলটি এখন একটি নিরাপদ প্রাথমিক storefront template। আপনার Supabase Project URL ও publishable/anon public key বসিয়ে সংযোগ করতে হবে। কখনো service_role বা secret key ওয়েবসাইটে বসাবেন না।

  1. Supabase → Project Settings → API থেকে Project URL এবং publishable key নিন।
  2. এই ফাইলের মধ্যে SUPABASE_URL ও SUPABASE_PUBLIC_KEY খুঁজে নিজের মান বসান।
  3. আপনার products টেবিলের কলামের নাম অনুযায়ী নিচের product field mapping মিলিয়ে নিতে হবে।
  4. লাইভ করার আগে database RLS policies এবং order submission flow পরীক্ষা করুন।

নিরাপত্তার জন্য এই প্রাথমিক ফাইলে customer order সরাসরি database-এ লেখা হয় না; আপনার orders টেবিলের সঠিক কলাম ও validation নিশ্চিত হলে সেটি যোগ করা উচিত।
